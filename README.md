# TrueNotification

**Parental control app for Android families.** See your child's call, SMS and app notification alerts, screen time, app usage, battery level and online status, with monitoring that is always visible on the child's phone.

[Get it on Google Play](https://play.google.com/store/apps/details?id=com.truenotification&utm_source=github) · [Website](https://truenotification.com/?utm_source=github) · Support: truenotification.help@gmail.com

## Features
- Real-time alerts for incoming calls, SMS and notifications from any app
- Daily screen time tracking
- App usage reports (games, social media, video)
- Battery level and online status of the child's phone
- Transparent monitoring: a visible notice on the child's device, no hidden spyware
- Data stored on TrueNotification's own server, not sold to advertisers

## How it works
1. Install TrueNotification on the parent's and the child's Android phones.
2. Link the two devices.
3. Start receiving alerts and daily usage reports.
